# ⚽ Premier League Match Outcome Analysis

## Project Overview
This project analyzes Premier League football match data using PostgreSQL.

## Dataset
- Total Records: 9,380 matches

## Tools Used
- PostgreSQL
- SQL
- GitHub

## Objectives
- Analyze home wins, away wins, and draws
- Identify top-performing teams
- Explore goal-scoring trends
- Practice SQL querying and data analysis

## Key SQL Concepts Used
- SELECT
- WHERE
- COUNT()
- GROUP BY
- ORDER BY
