# Project Summary

What makes a team win more matches? Does playing at home really provide an advantage? Which teams consistently perform better over time?

To answer these questions, I analyzed 9,380 Premier League matches using PostgreSQL. Through SQL queries and data exploration, I uncovered trends in match results, team performance, goals scored, and home vs away success rates.

This project demonstrates my ability to work with real-world datasets, organize data efficiently, and turn numbers into actionable insights using SQL.
